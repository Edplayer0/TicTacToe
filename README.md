# TicTacToe

Proyecto sencillo de aprendizaje para practicar HTML, CSS y lógica de juego en JavaScript.

Este repositorio contiene una versión básica del clásico juego de tres en raya, con el objetivo de reforzar conceptos como:

- Manipulación del DOM
- Lógica de juego
- Condiciones de victoria
- Estilos con Tailwind
- Estructuración de un proyecto web pequeño

## Características

- Tablero de 3x3
- Jugador contra jugador
- Detección de victoria o empate
- Diseño limpio y minimalista
- Proyecto fácil de entender y ampliar

## Tecnologías

- HTML
- CSS
- JavaScript
- Tailwind CSS

TicTacToe/

## Requisitos

- Node.js (si quieres compilar Tailwind)
- Un navegador web

## Ejecutar el proyecto

1. Clona el repositorio
2. Abre el archivo HTML generado o usa la compilación de Tailwind
3. Para compilar los estilos:

```bash
./build.sh
```

O en modo observación:

```bash
./watch.sh
```

## Nota

Este proyecto es un ejercicio de práctica para aprender cómo se construye una pequeña aplicación web con lógica de juego y diseño visual.
